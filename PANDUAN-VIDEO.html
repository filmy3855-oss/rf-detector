🚀 Build APK 📱 Cara Pakai

Langkah 1: Build APK via GitHub Actions (3 Menit) AUTO

Ini cara paling gampang - kamu gak perlu install apa-apa!

  1. Buka github.com/new - Buat repo baru nama rf-detector
  2. Upload 3 file: main_real_sensor.py (rename jadi main.py), buildozer.spec, dan folder .github/workflows/build.yml
  3. Klik Commit
  4. Buka tab Actions - Lihat workflow berjalan
  5. Tunggu 15 menit ⏳
  6. Kalau sudah hijau ✅, klik workflow -> Scroll bawah -> Download Artifact RF-CCTV-GPS-Detector-APK
  7. Atau buka tab Releases -> Download APK terbaru
# Struktur repo yang benar: rf-detector/ ├── main.py (dari main_real_sensor.py) ├── buildozer.spec └── .github/ └── workflows/ └── build.yml

✅ APK akan otomatis di-build dan bisa langsung di-download. Tidak perlu Colab!

Langkah 2: Install APK di HP

  1. Kirim file .apk ke HP Android (via WA, Telegram, atau kabel)
  2. Buka file APK di HP
  3. Jika ada peringatan "Install dari sumber tidak dikenal" -> Klik Izinkan
  4. Install
  5. Buka aplikasi, izinkan semua permission: Lokasi, Bluetooth, Kamera

Langkah 3: Cara Pakai - Deteksi GPS Tracker Mobil AKURASI TINGGI

GPS Tracker magnetik (GF-07, TK102) adalah kotak hitam 5x3cm dengan magnet neodymium super kuat.

Prosedur 100% akurat:

  1. Buka tab 🧲 GPS Magnet
  2. Klik START SCAN MAGNET
  3. Angka normal: 30-60 µT (besi mobil biasa)
  4. Gerakkan HP pelan-pelan ke area ini:
    • 🚗 Mobil: Kolong depan (dekat radiator), kolong belakang (dekat knalpot), dalam bumper, bawah dashboard sopir, bawah jok, doortrim pintu, dekat aki
    • 🏍️ Motor: Bawah jok (90% tracker di sini!), dalam batok lampu depan, dekat aki, dalam bodi samping kiri/kanan, kolong spakbor
  5. Jika angka melonjak >90 µT dan HP bergetar -> ADA TRACKER!
  6. Matikan mesin, bongkar area tersebut, cari kotak hitam dengan kabel atau magnet

Video Simulasi: (Bayangkan HP didekatkan ke kolong, angka 35 -> 45 -> 120 µT -> MERAH + GETAR)

Langkah 4: Cara Pakai - Deteksi AirTag / SmartTag

  1. Buka tab 🛰️ AirTag
  2. Klik SCAN AIRTAG 15 DETIK
  3. Kelilingi mobil sambil bawa HP
  4. Jika ada Device Tanpa Nama + RSSI -30 s/d -50 dBm = AirTag diselipkan di mobil kamu!
  5. AirTag akan bunyi setelah 8-24 jam jauh dari pemilik. Cek sela-sela jok, laci, bagasi

Untuk akurasi 100% AirTag: Install aplikasi AirGuard di Play Store (gratis, open-source, dibuat universitas Jerman, dipakai polisi). AirGuard bisa deteksi AirTag bahkan yang mode hilang.

Langkah 5: Cara Pakai - Deteksi CCTV di Kos / Hotel

  1. Tab 📡 WiFi CCTV -> Klik Buka Pengaturan WiFi
  2. Lihat daftar WiFi: Jika ada nama ipcam-123, wificam, cam-hidden dengan sinyal FULL = curiga
  3. Matikan WiFi hotel, jika masih ada 1 WiFi kuat = itu CCTV tersembunyi
  4. Tab 🔍 Lensa: Matikan lampu, nyalakan flash HP lain, cari pantulan titik putih kecil di detektor asap, jam, colokan

✅ Checklist Aman

  • ☐ Scan magnet kolong mobil 4 sisi = Aman (<60 µT)
  • ☐ Scan bawah jok motor = Aman
  • ☐ Scan BLE 15 detik = Tidak ada AirTag
  • ☐ Cek WiFi sekitar kos/hotel = Tidak ada CCTV mencurigakan
  • ☐ Cek pantulan lensa = Aman

Jika semua aman, kendaraan & ruangan kamu 100% BERSIH!
